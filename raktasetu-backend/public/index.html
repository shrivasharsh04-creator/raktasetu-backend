Security

Zero compromise
on data protection

Healthcare data is sacred. Every byte is encrypted. Every access is logged.

AES-256 Data Encryption

All sensitive data encrypted at rest and in transit. Aadhaar stored as secure hash — never reversible.

JWT Authentication

Stateless token-based auth with short expiry. Refresh token rotation prevents session hijacking.

Role-Based Access Control

Donor, Organization, and Admin roles with strict endpoint-level permissions. Zero privilege escalation.

One-Device Restriction

Donor accounts locked to one device. New login attempt triggers OTP re-verification and existing session termination.

SQL Injection Prevention

Parameterized queries via Spring Data JPA. No raw SQL exposed anywhere in the codebase.
